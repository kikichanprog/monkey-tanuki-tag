# おさるとたぬきの おにごっこ

🐒 お猿さんが鬼。でも追いかけるのは、たぬきさん！森で60秒間逃げきろう。

## ▶ ゲームであそぶ

https://kikichanprog.github.io/monkey-tanuki-tag/

## スマホでの操作

- 左のスティックに指を置き、そのまま動かすと移動。斜めにも動けます。
- 右のダッシュボタンを長押しすると加速。移動と同時に使えます。
- 指を離すと停止します。Ⅱ で一時停止。
- 縦持ち・横持ちに対応。画面の向きが変わると一時停止します。
- ゲーム盤と操作部が一画面に収まるレイアウトです。

## パソコンでの操作

- 矢印キー / WASD：移動
- スペース長押し：ダッシュ
- Escape / Ⅱ ボタン：一時停止・再開

## ルール

たぬきさんに捕まらず60秒過ごすとクリア。木や池をよけながらバナナを集めよう。バナナはダッシュの元気を回復するよ。

難易度は「やさしい」「ふつう」「むずかしい」。バナナの最高記録はブラウザーに保存します。別のタブに移ると自動で一時停止。音は最初はオフです。

## 開発

HTML・CSS・JavaScript を index.html にまとめた、外部ライブラリ不要のゲームです。ダウンロードしてブラウザーで開いても遊べます。キャラクターと森は Canvas の図形で描いています。

ブラウザー内の 320×568・390×844・844×390・768×1024 の表示と、ゲーム判定、スティックとダッシュの同時操作、指のキャンセル、一時停止時の入力解除を検証しています。実機の iOS / Android 端末では未検証です。
